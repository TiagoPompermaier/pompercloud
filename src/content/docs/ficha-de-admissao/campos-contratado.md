A aba **Contratado** recebe os dados do empregado e é **papel do cliente**: quem preenche é o próprio empregado ou o RH da empresa. O CV Digital tem exatamente os mesmos campos. Os documentos, a conta bancária e os dependentes estão em [Documentos, recebimento e dependentes](/ficha-de-admissao/campos-contratado-documentos/).

O CPF vem da abertura da ficha e não pode ser alterado.

## Dados do empregado: Identificação

| Campo | Obrigatório | Observação |
|---|---|---|
| Nome completo | Sim | |
| Nome social | Não | Só se o empregado usa um nome diferente do registro civil |
| CPF | Sim | Vem da abertura da ficha |
| Data de nascimento | Sim | |
| Sexo | Sim | |
| Raça / cor | Sim | Inclui a opção "Não informado" |
| Estado civil | Sim | |
| Grau de instrução | Sim | |
| Nacionalidade | Sim | Define se aparecem os campos de estrangeiro |
| Nome da mãe | Sim | |
| CPF da mãe | Não | Usado quando a mãe é gravada como dependente |
| Nascimento da mãe | Não | Obrigatório só se a mãe entrar no plano de saúde |
| Nome do pai | Não | |
| CPF do pai | Não | |
| Nascimento do pai | Não | Obrigatório só se o pai entrar no plano de saúde |

Os nomes da mãe e do pai também são levados ao sistema da folha como dependentes, com parentesco "Pai / mãe".

## Dados do empregado: Naturalidade

| Campo | Obrigatório | Observação |
|---|---|---|
| UF de nascimento | Sim | Fica como "EX" para quem não é brasileiro nato |
| Município de nascimento | Sim | Com UF "EX", vira **País de nascimento** |

A UF "EX" vale para estrangeiros, brasileiros nascidos no exterior e naturalizados. Ela é aplicada automaticamente quando a nacionalidade não é "Brasileiro".

## Dados do empregado: Acessibilidade

| Campo | Obrigatório | Observação |
|---|---|---|
| Deficiência física | Sim | Começa marcado como "Não" |
| Deficiência visual | Sim | Começa marcado como "Não" |
| Deficiência auditiva | Sim | Começa marcado como "Não" |
| Deficiência intelectual | Sim | Começa marcado como "Não" |
| Deficiência mental | Sim | Começa marcado como "Não" |
| Reabilitado pelo INSS | Sim | Começa marcado como "Não" |
| Ocupa vaga de cota (PCD) | Sim | Começa marcado como "Não" |
| Observação | Não | |

Quem tem laudo marca o que se aplica.
