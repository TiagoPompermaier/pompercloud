Estes campos também ficam na aba **Contratado** e são **papel do cliente**: preenchidos pelo empregado ou pelo RH da empresa. O CV Digital tem os mesmos campos. Identificação, endereço e acessibilidade estão em [Campos dos dados do empregado](/ficha-de-admissao/campos-contratado/).

## Dados do empregado: Documentos

| Campo | Obrigatório | Observação |
|---|---|---|
| É o primeiro emprego? | Sim | "Sim" só se o trabalhador nunca teve registro em carteira. Define o tipo de admissão na RAIS e no CAGED |
| PIS / PASEP | Não | Se não souber ou não tiver, deixe em branco |
| Data de cadastro no PIS | Não | |
| Usa carteira de trabalho digital | Sim | |
| Número, série, UF e expedição da CTPS | Não | Preencha só se não usa a carteira digital |
| RG, UF do RG e emissão | Não | |
| Título eleitoral, zona e seção | Não | |
| CNH, categoria e validade | Não | |
| Carteira de reservista | Não | |

Sem carteira digital, o número da CTPS passa a ser exigido na triagem da Pompermaier.

## Dados do empregado: Estrangeiro

Aparece só quando a nacionalidade não é "Brasileiro". Nenhum campo é obrigatório.

| Campo | Observação |
|---|---|
| País de origem | O país de nascimento é informado na seção Naturalidade |
| Data de naturalização | |
| Tempo de residência | Prazo indeterminado ou determinado |
| Tipo de visto | Temporário, permanente, refugiado, acordo Mercosul e outros |
| Data de chegada ao Brasil | |
| Casado(a) com brasileiro(a) | |
| Tem filhos brasileiros | |
| Carteira RNE e validade | |

## Dados do empregado: Recebimento

| Campo | Obrigatório | Observação |
|---|---|---|
| Tipo de conta | Não | Corrente, poupança, conta/cartão salário ou eletrônica |
| Banco | Não | Na ficha, escolhido da lista; no CV Digital, nome ou número por extenso |
| Agência | Não | Sem dígito |
| Número da conta e dígito | Não | |
| Usa Pix | Não | Não usa, Pix transferência ou Pix QR-Code |
| Tipo e chave Pix | Não | Telefone, e-mail, CPF ou dados bancários |

## Dados do empregado: Dependentes

Informe filhos, cônjuge ou outros dependentes, se houver. Ao começar a preencher um dependente, os campos obrigatórios dele passam a valer.

| Campo | Obrigatório | Observação |
|---|---|---|
| Nome | Sim | |
| Nascimento | Sim | |
| Parentesco | Sim | Filho, cônjuge, companheiro, enteado, filho universitário até 24 anos, menor sob tutela e outros |
| CPF | Sim | Precisa ser válido |
| Sexo | Sim | |
| Dependente de IR | Não | |
| Incapaz para o trabalho | Não | |
| Controle do IR | Não | Por mês ou por ano |
